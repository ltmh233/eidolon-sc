# SC gifts panel projection

The optional Go `-gifts-panel-token-file` flag moves the complete public `GET /api/gifts` projection into Go. It remains disabled without the flag. Python exposes one hidden, separately authenticated HTTP/1.1 duplex GET at `/api/_core/sc-gifts-panel`; public Go and Next never expose that path. Python's matching setting is `core_gifts_panel_token_path` / `EIDOLON_CORE_GIFTS_PANEL_TOKEN_FILE`.

The dedicated file follows the existing owner-only regular-file / 64 lowercase hex format. Both processes compare its contents with configured read and SC create credentials. It never grants arbitrary SQL, user selection, reward eligibility or draw/give/reset permissions. Admission follows dedicated credential, SC declarations, the original `UserId` dependency once, then the eight-dialog limit. Current sessions, consent, bans and safe-GET Origin behavior continue through the existing middleware.

The connection follows `sc-gifts-panel-v1`: begin and hello, daily raw facts and nonce-bound next/abort, global raw facts and nonce-bound next/abort, one original state/shown result, then finish, request EOF, end and response EOF. Every record is one strict UTF-8 JSON array and LF. Control phases are integer tokens, never booleans; records have exact shapes. Controls are bounded to 256 bytes per line, 1024 bytes total, four records and two pending records. Raw response history is not capped by bytes or declared counts, and declared counts never cause eager allocation.

Go preserves INTEGER/REAL exact comparisons, lazy TEXT/BLOB integer conversion under the Python 3.11 / Unicode 14 profile, TEXT-versus-BLOB key identity, duplicate rule identifiers, rule order, all historical stage dates and integer-equivalent stage keys. Global counts include old character identifiers and the BLOB empty key. It reuses the existing achievement scalar/time/int helpers, without reusing character completion or reward eligibility.

Python samples daily open/clock, global open and state/notice independently. Each raw read transaction finishes before waiting for the peer. Go performs the original early daily min and global comparisons before authorizing state. Invalid comparisons/dates therefore do not initialize balances; late `int` failures still leave original notice/replenishment commits intact. No transaction spans the dialog and no compensating rollback is added. An accepted next2 changes the owner state without an await before calling `Gifts.state`; duplicate controls can never call it twice.

The base object retains all nine original fields and is encoded with Pydantic's typed-dict JSON adapter, matching the actual original FastAPI response. The initial accepted v2 design incorrectly described this as ordinary `json.dumps(allow_nan=False)`. Formal unchanged-oracle tests found that original non-finite daily/base numbers become JSON `null`, and valid UTF-8 base BLOB values become strings. The implementation root recorded the §10 factual correction under the overriding requirement to preserve the old public API; the newly discovered facts and correction remain subject to the parent coordinator's closing review. Invalid UTF-8 and original `int(Inf)` still produce legacy 500. The original red counterexamples remain in the acceptance evidence. Go retains base values as raw JSON, preserving large integers.

Complete success and original handled 401/403/409/428 forward every real Set-Cookie separately, in order. Legacy 500 uses `text/plain; charset=utf-8`, `Internal Server Error`, and suppresses the private stream's early Cookies. Infrastructure 502 retains Cookies already received, while disclosing no private SQL or identity. A generic 502 also covers an old Python without the endpoint. A configured native failure never probes, retries or falls back.

One ASGI receive pump observes disconnects and a bounded control queue; one owner executes all business work. EOF before authorization, bad controls and observed disconnects prevent state. Cancellation after state is authorized cancels its coroutine, while a task already queued on the existing SQLite writer still completes under ADR-0028. There is no handle registry or recovery/replay mechanism. Dialogs have a fixed ten-second control idle and sixty-second monotonic absolute deadline. All exits stop the pump and release admission, including receive exceptions. Go independently closes both pipe ends on context cancellation, since `net/http.Do` can wait for its upload loop before returning.

The implementation root also recorded a §11 transport correction, still subject to the parent coordinator's closing review. Real parallel tests found that closing the HTTP response while the chunked control upload remained open could produce a TCP reset after a valid error/end, turning a legitimate legacy 500 into 502. Python now sends the error promptly, then uses the existing shared one-second closing budget to receive actual control EOF before sending end and final response completion. Disconnect, receive failure or missing EOF cannot produce a fabricated complete legacy termination; they remain bounded infrastructure failures. Error/end sends still respect the original sixty-second deadline. No business phase or state call can resume during this closing step.

The same race was independently reproduced for an original private 401 before the NDJSON response began. Only this hidden GET uses a dedicated route wrapper: it catches the original HTTPException, obtains the original FastAPI error status/body/headers, sends the headers so Go closes its writer, and sends that unchanged body after actual EOF within one closing budget. Credential, SC and UserId dependencies retain their original order and call count; global middleware and other routes are unchanged. Missing EOF, oversize controls and receive exceptions interrupt the rejected response rather than inventing a complete handled error. Implicit 405 and an old Python's 404 remain ordinary unavailable-version cases mapped to 502; this wrapper does not claim to cover them.

Production capacity, raw-history peak RSS and multi-worker deployment remain outside this acceptance. Eight conversations bound protocol admission, not SQLite writer queue length or response memory. Deploy new Python before enabling Go, and disable the flag before rolling Python back. Keep the direct HTTP/1 connection; buffering proxies and HTTP/2 are unsupported.
